# andreas-hemmeter.de

Startseite mit der Übersicht der Beiträge von Andreas Hemmeter. Wird über GitHub Pages unter `https://andreas-hemmeter.de` ausgeliefert; die Artikel liegen in eigenen Repositories (z. B. `Lernschleife`) und sind unter `https://andreas-hemmeter.de/<Repository>/` erreichbar.

- `index.html` – Übersichtsseite (neue Beiträge: den markierten `<article>`-Block kopieren)
- `impressum.html` – Impressum und Datenschutz
- `stil.css` – Gestaltung (Hell- und Dunkelmodus)
- `CNAME` – die eigene Domain für GitHub Pages
